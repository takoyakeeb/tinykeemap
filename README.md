# tinykeemap

自作キーボード [takoyaki8](https://github.com/takoyakeeb/takoyaki8) のキーマップを、ブラウザからUSB経由で読み書きする設定ツールです。

**使ってみる: https://takoyakeeb.github.io/tinykeemap/**

インストールは不要です。キーボードをUSBでつないで、上のページを開くだけで使えます。

## できること

- キーボードに接続して、全レイヤーのキーマップを表示する。キーの並びは、キーボードの形で表示する
- キーを選んで、割り当てる keycode を変更する(変更はすぐにキー入力へ反映される)。一覧から選ぶ。基本キー(英数字・記号・ファンクション・矢印・テンキーなど)と、修飾キー(Ctrl / Shift / Alt / GUI。左右別)がある
- 修飾キー付きのキー(Shift+A、Ctrl+C など)を、チェックボックスで割り当てる
- レイヤー切り替えキー(MO・TG・TO)を割り当てる
- 変更したキーを、1つだけ元に戻す
- 変更をキーボードのFlashに**保存**する(SAVE)。保存した内容は、電源を切っても残る
- 保存済みの内容を読み直す(LOAD)、初期キーマップに戻す(RESET)。RESET が戻すのは、キーボードが使っているキーマップだけで、保存済みの内容は、そのまま残ります。初期キーマップを保存したいときは、RESET のあとに SAVE も押します
- 保存していない変更があるキーとレイヤーに、● の印を出す
- keycode を、名前や16進で直接入力する(開発者向け)
- キーの並びを、KLE の JSON ファイルから読み込む

まだできないこと:

- LT・MT・DF など、ほかの種類のキー(レイヤーや修飾キーに関わるもの)や、メディアキー・マウスキーなど(takoyaki8 では、送るとエラーになります)
- レイヤー名の編集(名前は、機種ごとの既定の名前です)
- キー以外の設定(ロータリーエンコーダ、LED、OLED の表示 など)

## 使い方

1. キーボードをUSBでつなぎます。`picocom` などシリアルポートを開くソフトを使っている場合は、先に閉じてください(ポートは同時に1つのソフトしか開けません)。
2. 上のページを、PC版の **Chrome または Edge** で開きます。
3. 「接続する」を押して、表示されるポートの一覧からキーボードを選びます。
4. キーマップが表示されます。絵の上のタブで、レイヤーを切り替えます。変えたいキーのマスをクリックして選びます。もう一度押すと、選択が外れます。
5. 絵の下のパネルで、割り当てるキーを選びます。
   - 「キー」: 名前で探すか、カテゴリ(基本・英字・数字・矢印・F1〜F12・記号・その他)から選びます。
   - 「同時に押すキー」: Ctrl・Shift・Alt・GUI にチェックを入れると、修飾キー付きのキーになります(GUI は、Mac では ⌘、Windows では ⊞ です)。付けられるのは、基本キーだけで、左側の修飾キーだけです。
   - 「レイヤー切り替え」: 種類(押している間 = MO、押すたびに切り替え = TG、移る = TO)と、切り替え先のレイヤーを選びます。
6. 「変更後」の表示を確かめて、「変更する」を押します。そのキーだけを戻したいときは、「元に戻す」を押します。
7. 気に入ったら、上の「保存する」を押します。保存するまでは、USBを抜き差しすると、保存済みの内容に戻ります。

上の「読み直す」は、Flash に保存した内容を読み直します(未保存の変更は、破棄されます)。

### 「…」メニュー

接続すると、上の1行の右に「…」が出ます。

| 項目 | 内容 |
|---|---|
| 初期のキーマップに戻す… | RESET。確認が出ます。戻るのは、キーボードが使っているキーマップだけです(保存済みの内容は、そのまま) |
| 配列を読み込む… | キーの並びを、KLE の JSON ファイルから読み込みます(下の「キーの並びを変える」) |
| 読み込んだ配列を消す | 読み込んだ並びをやめて、内蔵の並びに戻します |
| keycode を直接入力… | 入力欄を、パネルの下に開きます(下の「keycode を直接入力する」) |
| デバイス情報・通信ログ | 機種名・キー数・レイヤー数と、通信の記録を見ます。うまくいかないときに使います |
| 再読み込み | キーボードの、いまの内容を読み込み直します。未保存の変更は、そのまま残ります(「読み直す」とは別です) |
| 切断する | 接続を閉じます |

### keycode を直接入力する

「…」メニューの「keycode を直接入力…」で、入力欄が開きます。名前または16進で書いて、Enter か「変更する」を押します(大文字・小文字は区別しません)。

| 種類 | 入力例 | 意味 |
|---|---|---|
| 基本キー | `KC_A`、`kc_esc`、`0x001D` | A、Esc、Z(16進の値でも入力できる) |
| 修飾キー付き | `LSFT(KC_A)` | Shift+A(`S(KC_A)` と短くも書ける) |
| | `LCTL(LSFT(KC_A))` | Ctrl+Shift+A(入れ子で組み合わせる) |
| | `RSFT(KC_A)` | 右 Shift+A |
| レイヤー切り替え | `MO(1)` | 押している間だけ、レイヤー 1 を有効にする |
| | `TG(1)` | 押すたびに、レイヤー 1 の有効・無効を切り替える |
| | `TO(0)` | 切り替えを解除して、レイヤー 0 に戻る(押している間の MO は残る) |

修飾キーを付けられるのは、基本キーだけです。左と右の修飾キーは、1つのキーに混ぜられません(`LCTL(RSFT(KC_A))` はエラー)。レイヤーの番号が、キーボードのレイヤー数以上のとき(レイヤーが4つなのに `MO(4)` など)は、ツールが警告を出し、キーボードも受け付けません。

### キーの並びを変える

キーの並びは、機種ごとに内蔵しています(takoyaki8 など)。内蔵がない機種は、行 × 列の格子で表示します。

別の並びを使いたいときは、[keyboard-layout-editor.com](https://www.keyboard-layout-editor.com/) の「Download JSON」で保存したファイルを、「…」メニューの「配列を読み込む…」で読み込みます。

- キーの左上の文字に「行,列」(例: `0,1`)を書くと、その位置のキーに対応づけます。文字がないときは、ファイルの順番で対応づけます(キーの数が、キーボードと同じときだけ)。
- 読むのは、キーの位置と大きさだけです。回転は、未対応です。
- 読み込んだ並びは、このブラウザに、機種ごとに記録します。ほかのブラウザやPCには、引き継がれません。

### 注意

- 保存(SAVE)はFlashに書き込みます。Flashは書き換え回数に限りがあるので、必要なときだけ保存してください。
- レイヤー切り替えキー(MO・TG)を割り当てるときは、移動先のレイヤーの同じ位置を `KC_TRANSPARENT`(透過)にしておくと、そのキーで元のレイヤーに戻せます。戻れなくなったときは、USBを抜き差しするか(どのレイヤーが有効かは保存されず、起動時はレイヤー 0 だけになります)、`TO(0)` を割り当てたキーを押すか、読み直す(LOAD)・初期キーマップに戻す(RESET)を使ってください。
- 「未保存の変更」は、接続したとき(または最後に保存・読み直しをしたとき)の内容との違いです。ツールはFlashの中身を直接は読めません。

### つながらないとき

- USBケーブルは、データ通信できるものを使ってください(充電専用のケーブルでは、つながりません)。
- ほかのアプリ(`picocom` など)が、同じポートを使っていないか確認してください。
- 「このブラウザでは使えません」と出たときは、PC版の Chrome か Edge で、同じページを開いてください。

## 対応ブラウザ

USB接続にWebSerialを使うため、WebSerialに対応した、PC版のChrome / Edge系のブラウザが必要です。FirefoxとSafari、スマートフォンのブラウザでは動きません。

## 対応キーボード

takoyaki8 で動作を確認しています。[通信プロトコル](docs/protocol.md)(`proto=1`)に対応したファームなら、他の機種でも使えます。キー数・行と列・レイヤー数は、接続時にキーボードから取得するので、機種ごとの専用コードはありません。キーの並びを機種に合わせたいときは、`devices.js` に定義を足すか、上の「配列を読み込む…」を使います。

修飾キー付きのキーとレイヤー切り替えキーは、ファームが対応している場合だけ使えます。対応していないファームは、そのキーの設定をエラーで断ります。

## ローカルで動かす

ビルドは不要です。このフォルダで、次を実行して、http://localhost:8000/ を開きます。

```
python3 -m http.server
```

`index.html` をファイルとして直接開いても動くことがありますが、うまく動かないときは、上の方法を使ってください。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `app.js` | 通信(WebSerial)、プロトコル、画面の動き |
| `keycodes.js` | keycode の名前の表と、入力欄の書き方(`LSFT(KC_A)`、`MO(1)` など)の読み取り(表示と入力の補助用。通信では名前を使わず、16進の値だけを送る) |
| `devices.js` | 機種ごとのキーの並び(KLE の JSON の形)と、既定のレイヤー名。表示のためだけの定義で、通信には関係しない |
| `style.css` | 見た目 |
| `docs/protocol.md` | 通信プロトコルの仕様(仕様の正) |
| `LICENSE` | ライセンス(MIT) |

## 通信プロトコル

USBシリアル(CDC)上の、1行1コマンドのテキストプロトコルです。`INFO` / `GET` / `SET` / `DUMP` / `SAVE` / `LOAD` / `RESET` があります。詳しくは [docs/protocol.md](docs/protocol.md) を見てください。

自分のキーボードのファームをこのプロトコルに合わせれば、このツールで設定できます。
