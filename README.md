# tinykeemap

自作キーボード [takoyaki8](https://github.com/takoyakeeb/takoyaki8) のキーマップを、ブラウザからUSB経由で読み書きする設定ツールです。

**使ってみる: https://takoyakeeb.github.io/tinykeemap/**

インストールは不要です。キーボードをUSBでつないで、上のページを開くだけで使えます。

## できること

- キーボードに接続して、全レイヤーのキーマップを表示する
- キーを選んで、割り当てる keycode を変更する(変更はすぐにキー入力へ反映される)。基本キー(英数字・記号・ファンクション・矢印・テンキーなど)と、修飾キー(Ctrl / Shift / Alt / GUI。左右別)を割り当てられる
- 修飾キー付きのキー(Shift+A、Ctrl+C など)を割り当てる。入力欄に `LSFT(KC_A)` のように書いて指定する
- レイヤー切り替えキー(MO・TG・TO)を割り当てる。一覧から選ぶか、`MO(1)` のように書いて指定する
- 変更をキーボードのFlashに**保存**する(SAVE)。保存した内容は、電源を切っても残る
- 保存済みの内容を読み直す(LOAD)、初期キーマップに戻す(RESET)
- 保存していない変更があるキーに、● の印を出す

まだできないこと:

- 修飾キー付きのキーを、一覧やチェックボックスで選ぶこと(今は、入力欄に書いて指定します)
- LT・MT・DF など、ほかの種類のキー(レイヤーや修飾キーに関わるもの)や、メディアキー・マウスキーなど(takoyaki8 では、送るとエラーになります)
- キー以外の設定(ロータリーエンコーダ、LED など)

## 使い方

1. キーボードをUSBでつなぎます。`picocom` などシリアルポートを開くソフトを使っている場合は、先に閉じてください(ポートは同時に1つのソフトしか開けません)。
2. 上のページを、**Chrome または Edge** で開きます。
3. 「接続する」を押して、表示されるポートの一覧からキーボードを選びます。
4. キーマップが表示されます。変えたいキーのマスをクリックして選びます。
5. 「キーの編集」で、割り当てる keycode を一覧から選ぶか、入力欄に書いて、「変更する」を押します。入力欄には、次のような書き方ができます(大文字・小文字は区別しません)。

   | 種類 | 入力例 | 意味 |
   |---|---|---|
   | 基本キー | `KC_A`、`kc_esc`、`0x001D` | A、Esc、Z(16進の値でも入力できる) |
   | 修飾キー付き | `LSFT(KC_A)` | Shift+A(`S(KC_A)` と短くも書ける) |
   | | `LCTL(LSFT(KC_A))` | Ctrl+Shift+A(入れ子で組み合わせる) |
   | | `RSFT(KC_A)` | 右 Shift+A |
   | レイヤー切り替え | `MO(1)` | 押している間だけ、レイヤー 1 を有効にする |
   | | `TG(1)` | 押すたびに、レイヤー 1 の有効・無効を切り替える |
   | | `TO(0)` | 切り替えをすべて解除して、レイヤー 0 に戻る |

   修飾キーを付けられるのは、基本キーだけです。左と右の修飾キーは、1つのキーに混ぜられません(`LCTL(RSFT(KC_A))` はエラー)。レイヤーの番号が、キーボードのレイヤー数以上のとき(レイヤーが4つなのに `MO(4)` など)は、ツールが警告を出し、キーボードも受け付けません。
6. 気に入ったら「保存する(SAVE)」を押します。保存するまでは、USBを抜き差しすると、保存済みの内容に戻ります。

注意:

- 保存(SAVE)はFlashに書き込みます。Flashは書き換え回数に限りがあるので、必要なときだけ保存してください。
- レイヤー切り替えキー(MO・TG)を割り当てるときは、移動先のレイヤーの同じ位置を `KC_TRANSPARENT`(透過)にしておくと、そのキーで元のレイヤーに戻せます。戻れなくなったときは、USBを抜き差しするか(どのレイヤーが有効かは保存されず、起動時はレイヤー 0 だけになります)、`TO(0)` を割り当てたキーを押すか、読み直す(LOAD)・初期キーマップに戻す(RESET)を使ってください。
- 「未保存の変更」は、接続したとき(または最後に保存・読み直しをしたとき)の内容との違いです。ツールはFlashの中身を直接は読めません。

## 対応ブラウザ

USB接続にWebSerialを使うため、WebSerialに対応したChrome / Edge系のブラウザが必要です。FirefoxとSafariでは動きません。

## 対応キーボード

takoyaki8 で動作を確認しています。[通信プロトコル](docs/protocol.md)(`proto=1`)に対応したファームなら、他の機種でも使えます。キー数・行と列・レイヤー数は、接続時にキーボードから取得するので、機種ごとの専用コードはありません。

修飾キー付きのキーとレイヤー切り替えキーは、ファームが対応している場合だけ使えます。対応していないファームは、そのキーの設定をエラーで断ります。

## ローカルで動かす

ビルドは不要です。このフォルダで、次を実行して、http://localhost:8000/ を開きます。

```
python3 -m http.server
```

`index.html` をファイルとして直接開いても動くことがありますが、うまく動かないときは、上の方法を使ってください。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `app.js` | 通信(WebSerial)、プロトコル、画面の動き |
| `keycodes.js` | keycode の名前の表と、入力欄の書き方(`LSFT(KC_A)`、`MO(1)` など)の読み取り(表示と入力の補助用。通信では名前を使わず、16進の値だけを送る) |
| `style.css` | 見た目 |
| `docs/protocol.md` | 通信プロトコルの仕様(仕様の正) |
| `LICENSE` | ライセンス(MIT) |

## 通信プロトコル

USBシリアル(CDC)上の、1行1コマンドのテキストプロトコルです。`INFO` / `GET` / `SET` / `DUMP` / `SAVE` / `LOAD` / `RESET` があります。詳しくは [docs/protocol.md](docs/protocol.md) を見てください。

自分のキーボードのファームをこのプロトコルに合わせれば、このツールで設定できます。
